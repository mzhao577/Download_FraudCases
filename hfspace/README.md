# Fraud Case Review — Prevention Design

A Streamlit port of the local `webtool2`: 679 prosecuted DOJ health-care fraud
cases from 2025, each with the prevention design generated by
`designFeatures_v2` — how the case could have been caught **before the claims
were paid**, and the automated checks to build.

## Reading order

Same as the local tool: the case list on the left, and on the right the title,
the `SchemeSummary`, then the prevention block, then every other field.

| Block | Contents |
|---|---|
| **Title** | `DocumentName`, with `FraudType` and `CaseStatus` as chips |
| **Summary** | `SchemeSummary` |
| **Prevention design** | `DesiredServiceGroups`, `WaysToIdentify`, `FeaturesToCreate`, `FeatureCategory` |
| **All other fields** | The remaining 14 columns, collapsed |

The prevention block is **data-driven, not hard-coded**: every column positioned
after the summary column in the CSV renders there. Add a fifth analysis column
and it appears with no code change. Semicolon lists render as pills; the
numbered `1) … 2) … 3)` checks render as a numbered list.

## Controls

Free-text search across every column, a tab dimension selectable from
`FeatureCategory` / `FraudType` / `Service` / `CaseStatus`, and
`⇤ First │ −50 │ −10 │ ← Previous │ Next → │ +10 │ +50 │ Last ⇥` navigation.
Tab counts follow the search but precede the tab filter, so selecting one tab
does not blank the others.

## How it runs

Hugging Face retired the server-side Streamlit SDK, and its Docker replacement
requires a paid plan, so this is a **static Space**: `index.html` boots
[stlite](https://github.com/whitphx/stlite) (Streamlit on Pyodide/WebAssembly)
and runs `app.py` entirely in the browser. Nothing is uploaded, and the first
load fetches the Python runtime and pandas before caching them.

The same `app.py` runs unchanged against a normal Streamlit server:

```bash
pip install streamlit pandas
streamlit run app.py
```

A `Dockerfile` is included for deploying it as a server-side Space on an
account with Docker Spaces enabled.

## Data

`data/extractedSummary_2025_DOJ_withFeatures.csv` — 679 rows × 19 columns,
built by `designFeatures_v2/step3_build_csv.py`. The source PDFs are not
shipped; every field shown here comes from the CSV.

Case text is summarised from public DOJ press releases. The prevention designs
are model-generated reconstructions of what *would* have been visible in claims
data — none has been tested against real claim lines, and every threshold needs
calibration against a control population before use.
